Toda la información del local, fácil de encontrar.

El sitio web presenta el establecimiento y facilita el acceso a la información práctica. El contenido exacto se acuerda para cada proyecto.

01 / MENÚ

Menú y precios

Platos, productos o servicios y sus precios, según la información proporcionada por el establecimiento.

02 / VISITA

Ubicación y horario

Las fotos, el horario y la información del negocio ayudan a planificar la visita.

03 / CONTACTO

Contacto y cómo llegar

Datos de contacto, mapa y enlaces a redes sociales o mensajería.

PRECIOS

Precios claros de creación y mantenimiento.

Creación del sitio web — 10.000 ₽. El primer mes de mantenimiento es gratis.

  • Desde el segundo mes: 5.000 ₽/mes — sitio web llave en mano.
  • Desde el segundo mes: 7.500 ₽/mes — sitio web con soporte básico de contenido.
  • Desde el segundo mes: 10.000 ₽/mes — sitio web con soporte activo.

PREGUNTAS FRECUENTES

Antes de iniciar el proyecto.

¿Se pueden incluir el menú, los precios y el horario?

Sí. El sitio de una página puede incluir información sobre productos y servicios, precios, fotos, contactos y horario.

¿Cuánto cuesta un sitio web para una cafetería?

La creación cuesta 10.000 ₽. El primer mes de mantenimiento es gratis. Desde el segundo mes, el mantenimiento cuesta 5.000, 7.500 o 10.000 ₽ al mes, según el plan elegido.

¿Se puede actualizar la información después del lanzamiento?

El plan de soporte básico incluye una actualización programada al mes; el plan de soporte activo incluye tres. Las tareas adicionales acordadas en los dos primeros planes cuestan 2.000 ₽ cada una. Las páginas nuevas, las funciones complejas y los rediseños importantes se presupuestan por separado.
