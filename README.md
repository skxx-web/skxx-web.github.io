# k web — Cloudflare Pages

Чистая статическая версия маркетингового сайта kxxweb.ru. Главная страница — обычные HTML/CSS без React runtime, авторизации, API-запросов и внешних скриптов. Визуальная разметка и тексты перенесены из ранее опубликованной версии.

Проект «Телецбург» опубликован на том же домене по `/Teletsburg/`; исходный репозиторий `skxx-web/Teletsburg` сохранён отдельно.

## Публикация

GitHub Actions автоматически публикует каталог `public/` в Cloudflare Pages (`kxxweb-site`) при каждом push в `main`. Команда сборки не нужна.
