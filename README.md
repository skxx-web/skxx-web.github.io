# k web — статический сайт

Маркетинговый сайт k web на обычных HTML/CSS/JavaScript без обязательного backend или клиентского рендеринга. Русская главная опубликована на `/`, английская версия — на `/en/`. Страница проекта «Телецбург» является кейсом веб-разработчика, а на реальный сайт ресторана ведёт ссылка на `https://teletsburg.site/`; английский кейс доступен на `/en/Teletsburg/`.

## Публикация

GitHub Pages публикует статический сайт из корня репозитория. GitHub Actions публикует тот же набор файлов в Cloudflare Pages (`kxxweb-site`) при каждом push в `main`. Перед отправкой Cloudflare workflow синхронизирует каталог `public/` из корня командой `node .github/scripts/sync-public.mjs`; изменения сайта следует вносить в корневые файлы и каталоги. Скрипт исключает GitHub-настройки, `CNAME`, README и сам каталог `public/`, но копирует страницы, ресурсы, favicon, sitemap и robots.txt.

Сайт доступен без сборки приложения. `sitemap.xml` содержит только публичные индексируемые страницы, а парные страницы RU/EN связаны через `hreflang` и canonical.
